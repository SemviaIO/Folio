# Folio

Folio is a desktop workspace where a subject matter expert and their agent
build a model of their domain, bind it to the databases, APIs, data lakes and
spreadsheets that already hold the data, and query it across sources. The
domain model is written in open W3C standards (RDF, RDFS, SHACL and SKOS), and
agents connect to it over the Model Context Protocol (MCP).

Folio runs on your own computer: no server, no graph database, no pipeline.

Folio is in public beta. Keep backups of your workspace and hold off on
production use.
